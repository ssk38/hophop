# Hophop

Geometry Dash を意識した高速なブラウザ ゲーム。4 面構成で、それぞれ異なるテーマと難易度が用意されています。

## 公開ページ

公開版は以下でプレイできます。

https://ssk38.github.io/hophop/

## 遊び方

- Space、W、または ↑ でジャンプします。
- 床のトゲや天井のトゲを避けて進みます。
- 敵に触れると爆発演出の後、スコア減点付きで同じ位置から再開します。
- 最初は 3 ライフです。死亡ごとにスコアが半分になり、ライフを 1 失います。ライフが 0 になるとゲームオーバーです。
- スター状態は点滅し、3 秒間は敵やトゲに当たっても無敵になります。
- スター状態中に敵に当たると敵が破壊され、爆発して 100 点が入ります。
- 速度アップ、スローダウン、縮小、スター取得などのアイテムを集めます。
- 速度アップアイテムは 500 点、その他のアイテムは 100 点です。獲得時の点数はプレイヤーの上に浮かびます。
- 1UP アイテムを取ると 1 ライフ追加です。
- ランダムに出る大きなポータルに入ると次のステージに進めます。最初のポータルは 10 秒後、見逃した場合は 3 秒ごとに再出現します。
- ポータルに入ると 1,000 点追加されます。
- ステージ遷移時には 3 秒のステージ番号カウントダウンが表示され、BGM はそのまま流れます。
- 各ステージで背景の模様が変わり、衝突時には粒子エフェクトが出ます。
- 4 面すべてをクリアするとクリア画面に進みます。
- スタート画面や終了画面から Top 10 スコアを確認できます。ベスト 3 は強調表示されます。

## コード構成

- `stage-config.js`: ステージごとのテーマと難易度設定
- `game.js`: ゲーム状態、物理演算、衝突判定、進行管理
- `renderer.js`: Canvas 描画と浮かぶスコア表示
- `audio.js`: 合成音楽と効果音
- `leaderboard.js`: Top 10 スコアの保存と表示
- `item-score.js`: アイテムごとの得点
- `enemies.js`: 敵の生成、移動、衝突判定
- `death-effects.js`: 死亡時の爆発粒子演出

## ローカル実行方法

このフォルダで以下を実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで http://localhost:8000 を開いてください。
